# Redisseny d'ESSTRAPIS · proposta A

Maquetes del redisseny de l'aplicació ESSTRAPIS (gestió de projectes, hores i diners per a cooperatives).
Comenceu per `index.html`.

- `index.html`: les 52 pantalles de la proposta A per àrea, i la comparativa inicial de les propostes A · B · C.
- `screens/A-*.html`: cada pantalla en HTML estàtic. Les noves fan servir `assets/a.css`; `A-Login`, `A-Llistat`, `A-Fitxa` i `A-Edicio` porten estils en línia.
- `screens/A-_plantilla.html`: punt de partida per a pantalles noves.
- `assets/a.css`: colors, tipografia i components de la proposta A.
- `png/`: captura de cada pantalla a 1440 px.
- `screens/B-*`, `screens/C-*`, `screens/Actual-*`, `source/`: la comparativa inicial i els fitxers originals.

**Dades**: totes les dades que hi surten són inventades (persones, entitats, projectes, adreces, NIF i imports).
Les pantalles de logística no hi són.
