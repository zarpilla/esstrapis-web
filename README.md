# ESSTRAPIS · web

Web pública d'ESSTRAPIS, l'aplicació de gestió de projectes, hores i diners per a cooperatives i entitats de l'economia social i solidària.

- `index.html`: la pàgina de presentació.
- [`redisseny-v2/`](redisseny-v2/): maquetes del redisseny de l'aplicació (proposta A). Obriu `redisseny-v2/index.html`.

Totes les dades que surten a les maquetes són inventades.
- Secció «ESSTrapis en xifres»: les dades són a `assets/js/xifres.js`. Per actualitzar-les, `tools/xifres/actualitza-xifres.sh` (consultes a `tools/xifres/xifres.sql`; només llegeix les BD dels tenants del VPS) escriu les línies per enganxar-hi. `tools/` no es publica.
